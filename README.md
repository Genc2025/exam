# Exam Hall

Original exam-prep SPA built for GitHub Pages.

## Structure
- `index.html` — entry point
- `src/main.js` — application logic
- `src/data.js` — lessons, questions, and flashcards
- `src/styles.css` — UI styling
- `manifest.webmanifest` — PWA metadata

## Local run
Open `index.html` in a browser, or serve the folder with any static server.

## GitHub Pages
1. Open the repository settings.
2. Enable GitHub Pages.
3. Set the source to the default branch.
4. Use the root folder.

The app is static and does not need a backend.
